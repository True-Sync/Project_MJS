# Project_MJS

> **Development Discontinued — September 2026**

Unreal Engine 5 기반의 3D 스타일리시 액션 게임 프로젝트입니다.

## Development Status

프로젝트 개발은 약 2개월간 진행되었으며, 다음과 같은 핵심 시스템의 구현 및 프로토타이핑이 진행되었습니다.

- 플레이어 이동 및 전투 시스템
- 타겟팅, HP / Stamina, 회피 및 스킬 시스템
- Sequencer 기반 시네마틱 시스템
- Gameplay Tag 기반 VFX 실행 시스템
- 메인 메뉴 / Pause UI
- 런타임 비동기 에셋 로딩
- 기초 하우징 시스템
- Hub / Stage / Boss Level Grayboxing
- FMOD 사운드 및 일부 그래픽스 기능 연동

게임플레이의 핵심 시스템은 프로토타입 단계까지 구현되었으나,
캐릭터·배경·프랍 등의 아트 리소스 제작 및 최종 콘텐츠 통합,
레벨 디테일링과 폴리싱은 완료되지 않았습니다.

## Discontinuation

전체 제작 일정과 리소스 제작 일정의 차이로 인해
예정된 전시 일정 내에 목표 스코프와 품질을 모두 달성하기 어렵다고 판단하여,
2026년 9월 프로젝트 개발을 중단하였습니다.
